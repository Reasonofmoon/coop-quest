# Contributing

Useful contributions beat counters. Please report a reproducible bug, improve accessibility or translations, or add tests for evidence parsing.

- Never add invented coauthors, fake accepted answers, or star exchanges.
- Keep the app dependency-free, credential-free, and usable without starring.
- Do not submit private repository data, tokens, names, or email addresses in an issue. Use sanitized fixtures.
- Keep imported, candidate, linked-author, and official GitHub achievement states distinct.
- Explain how you tested your change. AI-assisted contributions are welcome when the contributor reviews the output and states any unverified claims.

Open a focused pull request with the problem, solution, and checks.
